## 2. Задачи

### 2.1 Вход и формы логина

Все входы — **одна форма по номеру телефона** с кодом через WhatsApp, Telegram или SMS. Роль определяется номером.

| Форма / точка входа | Для кого | Как выдаётся доступ |
|---|---|---|
| `/ru/login` — после входа возвращает на исходную страницу | все | — |
| Встроенный вход на шаге оформления заказа `/ru/book/<услуга>` | клиент | новый номер = новый клиент |
| Шаг «Как вас зовут?» | новый пользователь | сразу после первого кода |
| `/ru/account` — профиль, адреса, заказы, подписки, отзывы | клиент | любой номер |
| `/ru/pro` — кабинет мастера | мастер | номер в профиле мастера (Админка → Мастера), роль выдаётся при первом входе |
| `/ru/admin` — админка | оператор, администратор, владелец | роль по номеру в Админка → Сотрудники; владелец — `ADMIN_PHONE` в `.env` |
| Выход | все | кнопка в профиле |

Права в админке: **оператор** — заказы, расписание, клиенты, отзывы; **администратор** — плюс услуги, мастера, промокоды, баннеры, страницы, переводы, журнал; **владелец** — всё, включая настройки и сотрудников.
