**Решения владельца FLOW-2 (30.09.2026, все — вариант А):**
- **Корзина:** несколько услуг разных категорий; разные мастера и слоты по позициям → FLOW-3.

## Шаг 1 — Главная + точка входа с адресом

### Экран

**Телефон (360 px):**
- Шапка: логотип слева, строка «Ереван, …» с адресом (или «Выбрать адрес» для гостя) — тап открывает выбор адреса.
- Поиск услуг.
- Сетка категорий 2×N: карточки с фото, названием, ценой «от … ֏» и бейджем минимальной длительности.
- Промо-карусель (баннеры из БД).
- Секция «Как это работает» — 3 шага. Блок «Обещания» — 4 карточки.

**Компьютер (1440 px):** контейнер 1200 px, заголовок + поиск — 5 колонок, плитки категорий 3×N — 7 колонок.

### Данные и правила

| Поле | Источник | Правило |
|------|----------|---------|
| Список категорий | `getHome()` | active=true, archived=false; comingSoon=true → плашка «Скоро», ссылка null |
| Цена «от …» | `serviceCard().fromPrice` | Минимум из option.price > 0; целые драмы |
| Длительность «от … ч» | `serviceCard().minDuration` | Минимум из option.durationMin > 0; поля service.durationMin нет |
| Адрес в шапке | localStorage / сессия | Гость видит «Ереван», вошедший — свой сохранённый адрес (FLOW-9) |
| Баннеры | `Banner`, placement CAROUSEL_HOME | Управляются в админке |

### Что при ошибке

- База недоступна: Suspense-граница, shell без данных.
- Нет категорий: пустое состояние + предложение написать в WhatsApp.

### Что уже есть в iHelp

`src/app/[locale]/(site)/page.tsx`, `src/components/home/HeroSection.tsx` (сетка категорий), `src/components/home/SubcategoriesSheet.tsx` (sheet составной категории, DSN-11 done).

### Что закрывает разрыв

- **FLOW-9** — адрес в шапке: выбор для гостя, хранение для вошедшего.
- **FLOW-8** — поиск по каталогу.
- **DSN-1** — макет главной как у маркетплейса (в разработке).
- **CONTENT-13** — плитки «Скоро» ведут на экран «Уведомить меня».

## Шаг 2 — Страница категории

### Экран

**Телефон:**
- Шапка: ← назад, название категории.
- Блок форматов «Разовый / Подписка / Пакет» (только при showFormats=true — COMP-34).

- Плашка «Скоро в iHelp» для comingSoon=true.
- Тап на составную категорию на главной → SubcategoriesSheet снизу.

**Разделы подкатегорий (разрыв — CONTENT-17):**
Urban Company показывает: категория → именованные разделы (например «Уборка квартиры», «Уборка офиса») → плитки-услуги с иконками. В схеме iHelp поле `section` всегда `null` (catalog.ts:39). SubcategoriesSheet умеет показывать заголовки разделов (showSectionHeaders при groups.length > 1), но данных нет. Разрыв: добавить разделы в схему категории и заполнить через админку → CONTENT-17.

**Экран «Уведомить меня» (CONTENT-13):**
При клике на comingSoon=true → страница/модалка с полем телефон/e-mail + кнопкой «Уведомить». Тексты: `notifyButton`, `notifyTitle` из `messages/ru.json`. Куда уходит: запись в БД или Telegram-уведомление команде. Клиент видит: «Спасибо! Сообщим, когда услуга появится».

## Шаг 3 — Список услуг и форматы

### Экран

Карточки услуг на странице категории или в SubcategoriesSheet. Тарифная сетка каждой услуги: строки = OptionGroup (например «Площадь квартиры»), ячейки = Option (название + цена + длительность). Опции управляются в `admin/services/[id]`. Скидка плана (`plan.discountPercent`) показывается при выборе формата «подписка».

### Данные и правила

| Поле | Источник | Правило |
|------|----------|---------|
| Группы опций | `service.groups[].options[]` | active=true, по sort |
| Цена опции | `option.price` | Целые драмы |
| Длительность опции | `option.durationMin` | Показывается, если > 0 |
| Скидка плана | `plan.discountPercent` | «до −N%» рядом с форматом подписки |

### Что закрывает разрыв

- **COMP-26** — объяснение форматов. **FLOW-10** — тарифная сетка в карточке.

## Шаг 5 — Корзина и допродажи

### Решение владельца (FLOW-2, вариант А)

Корзина поддерживает несколько услуг разных категорий. Один заказ — несколько позиций с разными мастерами и слотами. Следствие: заказ из нескольких позиций/визитов — архитектурная задача FLOW-3.

### Экран

`StickyCartBar` (DSN-12 done): плавающая плашка снизу, появляется когда корзина не пуста. Скрыта на `/s/` и `/book/` (HIDE_ON). Корзина сейчас — localStorage, одна позиция (CartEntry: slug, opts, planId, count, total).

После FLOW-3: список позиций, итог, позитивное подкрепление «Вы сэкономили N ֏», кросс-продажа.

### Данные и правила

| Поле | Источник | Правило |
|------|----------|---------|
| Позиции корзины | localStorage → CartEntry (сейчас 1 позиция) | После FLOW-3 — массив |
| Итог | Сумма total по позициям | Пересчитывается при изменении |

### Что уже есть в iHelp

`src/components/StickyCartBar.tsx`, `src/lib/cart.ts`.

### Что закрывает разрыв

- **FLOW-3** — многопозиционная корзина: несколько услуг, разные мастера и слоты по позициям.

- Комментарий к заказу.
- Кнопка «Подтвердить заказ».

### Данные и правила

## Шаг 10 — Отслеживание заказа

### Экран

`/account/orders/[id]`: статус заказа и лента визитов. Карточка мастера: фото, имя, рейтинг, кнопка «Позвонить / написать» (настоящий номер, FLOW-2 вариант А). Кнопки «Перенести» / «Отменить» (до freeCancelHours=24). Кнопка «Поддержка» → WhatsApp/Telegram.

### Реальные статусы (schema.prisma:266,336)

**OrderStatus:** `ACTIVE` / `PAUSED` / `COMPLETED` / `CANCELLED`

**VisitStatus:**
- `UNSCHEDULED` — дата не назначена
- `SCHEDULED` — забронирован мастер и время
- `CONFIRMED` — подтверждён мастером
- `ON_WAY` — мастер в пути
- `IN_PROGRESS` — мастер на объекте
- `DONE` — завершён
- `CANCELLED` — отменён
- `SKIPPED` — пропущен (подписка)
- `NO_SHOW` — клиент не открыл дверь

Лента строится по визитам (по полю `index`).

### Правила отмены и переноса

- Отменить визит: статус SCHEDULED/CONFIRMED и до визита > freeCancelHours (24 ч) — `account.ts:73-88`. Ошибка `"late"` если срок вышел.
- Перенести визит: UNSCHEDULED/SCHEDULED/CONFIRMED, те же правила — `account.ts:90-110`. Ошибка `"late"`.
- При IN_PROGRESS и ON_WAY — отмена недоступна.

### Что уже есть в iHelp

`src/server/actions/account.ts:cancelVisitAction, rescheduleVisitAction, cancelOrderAction`. `src/app/[locale]/(site)/account/orders/[id]/page.tsx`.

### Что закрывает разрыв

- **FLOW-12** — трекер в реальном времени (ON_WAY с картой / отсчётом).
- **FLOW-5** — уведомления о переходах статусов.
- **FLOW-7** — канал поддержки изнутри заказа.
