# Подписки и пакеты

Сверено с кодом: 28.09.2026, коммит 5a23c30. Совпадает с записями nocode-1 в ленте DEV-15 от 25.09.2026 (коммит 6d81bcf): расхождений нет.

## Правила

### Типы заказов

1. **`SUBSCRIPTION`** — повторные визиты по расписанию. Визиты генерируются автоматически по правилам `Recurrence`. Не имеет фиксированного числа визитов.
2. **`PACKAGE`** — N предоплаченных визитов. При создании создаётся первый визит (`SCHEDULED`), остальные N−1 — в статусе `UNSCHEDULED` (без даты и мастера).

### Recurrence (расписание подписки)

3. Структура: `{ start: YYYY-MM-DD, time: HH:MM, weekdays: number[], intervalDays: 7|14|28 }`.
4. `intervalDays` определяет частоту: 7 = еженедельно, 14 = раз в две недели, 28 = раз в месяц.
5. `weekdays` — дни недели (1=пн..7=вс). Если пустой — используется день недели из поля `start`.

### Генерация визитов подписки

6. Горизонт генерации: `subscriptionHorizonDays=28` дней вперёд.
7. Генерация происходит при создании заказа, а также в кроне каждые 15 минут (когда до конца горизонта менее 3 дней).
8. Если свободного мастера нет при генерации визита подписки, `masterId=null`. Команда получает предупреждение каждый вечер в 18:00 (шаг `unassigned` в кроне).

### Пауза и возобновление

9. Пауза: `status=PAUSED`, `pausedUntil=<дата>`. Возобновление — крон видит `pausedUntil <= now` и вызывает `resumeSubscription`.
10. При возобновлении будущие визиты в статусе `SKIPPED` удаляются, затем генерируются заново (иначе они занимали бы слоты).

### Истечение пакета

11. Пакет имеет поле `expiresAt = createdAt + validityDays`. Крон (шаг `packages`) ежедневно ищет `ACTIVE` пакеты с `expiresAt < now`:
    - переводит `UNSCHEDULED`-визиты в `CANCELLED`;
    - закрывает пакет;
    - уведомляет команду, если остались неиспользованные визиты.

### Многодневная подписка

12. Для `visitsPerWeek > 1` нужны несколько дней в `weekdays`. День `start` всегда включается в `weekdays` (если не был там явно).

## Крайние случаи

- **Нет свободного мастера для подписки.** `masterId=null`, следующим вечером 18:00 тех-уведомление команде.
- **Пакет из 1 визита.** При создании — один `SCHEDULED`-визит; `UNSCHEDULED`-визитов нет.
- **Пустой `weekdays`.** Используется `isoWeekday(start)` — день недели первого визита.
- **Горизонт заканчивается.** Крон каждые 15 минут проверяет и при необходимости продлевает.
