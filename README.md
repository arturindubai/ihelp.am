# HomeCare — платформа бытовых услуг (Ереван)

Web-app в стиле Urban Company: каталог услуг → параметры и калькулятор → адрес, дата, время, мастер → оплата наличными (картой — после подключения эквайринга) → личный кабинет. Сверху: кабинет мастера и админка с полным управлением.

> Рабочее название «HomeCare» и цвета — временные. Название меняется в **Админка → Настройки → Компания**, логотип — `public/img/icon.svg` и `src/app/icon.svg`, фирменные цвета — в начале `src/app/globals.css`.

## Стек

| Слой | Технология |
|---|---|
| Фронт + бэкенд | Next.js 15 (App Router, Server Actions), React 19, TypeScript |
| Стили | Tailwind CSS 4, mobile-first |
| База | PostgreSQL 16 + Prisma 6 |
| Языки | next-intl: `/ru`, `/en`, `/am` (в интерфейсе RU / ENG / ARM, для SEO `hy`) |
| Деплой | Docker Compose: app + Postgres + Caddy (HTTPS) + cron + ежедневный бэкап |

## Что умеет

**Клиент**
- Каталог категорий (включая «Скоро»), страница услуги как у Urban: шаги выбора, пример расписания, «что входит в материалы», тарифы, преимущества, FAQ, отзывы, мастера.
- Калькулятор: длительность, материалы, допуслуги, тарифы (разово / раз в месяц / 2 раза в месяц / еженедельно / 2+ в неделю с выбором дней / пакет визитов). Цена пересчитывается сразу, зачёркнутая цена, «−X%».
- Промокоды (%, фикс. сумма, лимиты, сроки, «только первый заказ», привязка к услугам и типам тарифа).
- Вход по номеру: код через WhatsApp, Telegram или SMS.
- Оформление: адреса, свободные слоты с учётом графиков и занятости мастеров, выбор мастера или «любой», наличные, комментарий.
- Профиль: личные данные, адреса, заказы (предстоящие / подписки и пакеты / история), перенос, отмена, пропуск визита, пауза и возобновление подписки, планирование визитов пакета, отзыв после визита.

**Мастер** (`/ru/pro`) — визиты на сегодня и ближайшие, адрес, звонок, маршрут, статусы «Выехал → Начал → Завершил», «Получил наличные», сумма наличных за день, рейтинг.

**Админка** (`/ru/admin`)
- Дашборд: визиты, выручка, подписки, загрузка мастеров, доля первых визитов (ключевая метрика из unit-экономики), визиты без мастера, наличные к сдаче.
- Заказы: поиск и фильтры, карточка заказа, назначение и смена мастера, перенос, статусы, отметка наличных, добавление визитов, пауза и отмена.
- Расписание по дням и мастерам.
- Услуги и категории: создание, редактирование, дублирование, удаление (при наличии заказов — архив). Все шаги, варианты, цены, время, скидки, тарифы, пример расписания, контент страницы — на трёх языках.
- Мастера: профиль, фото, телефон для входа в кабинет, услуги, рабочие часы, отпуска.
- Клиенты, отзывы (модерация, ответ), промокоды, баннеры, страницы (оферта и т.д.), тексты интерфейса и переводы, настройки, сотрудники и роли, журнал действий.

Роли: **Оператор** — заказы, расписание, клиенты, отзывы. **Администратор** — всё, кроме настроек и сотрудников. **Владелец** — полный доступ.

## Тарифная сетка

Стартовые данные (`prisma/seed.ts`) взяты из `Yerevan_Cleaning_Unit_Economics_2026.xlsx`:
- первый час 9 000 ֏, каждые следующие 30 минут +3 500 ֏ (1 ч … 4 ч);
- материалы +1 000 ֏ (скидки на материалы не действуют);
- 2 раза в месяц −3%, еженедельно −5%, 2+ раза в неделю −7%;
- первый визит −25% при подписке или пакете от 4 визитов, иначе −10%;
- скидки не суммируются, цена округляется до 50 ֏.

Все значения меняются в админке. Правила движка цены покрыты тестами: `npm test`.

## Языки

- Все тексты интерфейса — в `messages/ru.json` (ключи). `en.json` и `am.json` пока пустые: всё, что не переведено, показывается на русском.
- Переводить можно двумя способами: заполнить JSON-файлы или в **Админка → Тексты и переводы** (фильтр «Только непереведённые»).
- Контент из базы (услуги, тарифы, мастера, FAQ, баннеры, страницы) переводится во вкладках RU / ENG / ARM прямо в формах.
- Когда перевод готов: **Настройки → Языки сайта** → включить ENG / ARM. Появится переключатель языка.

## Локальная разработка

```bash
npm install
cp .env.example .env          # укажите DATABASE_URL на локальный Postgres
npx prisma migrate dev
npm run db:seed
npm run dev                   # http://localhost:3000/ru
npm test                      # unit-тесты цены, слотов, расписания подписок
```

Для локальных тестов в `.env` поставьте `OTP_DEV_MODE=true` — код подтверждения появится на экране.

## Деплой на Contabo (Ubuntu 22.04/24.04)

```bash
# 1. Docker
curl -fsSL https://get.docker.com | sh

# 2. Код
git clone <repo> /opt/homecare && cd /opt/homecare     # или загрузите архив

# 3. Настройки
cp .env.example .env
nano .env
#   POSTGRES_PASSWORD, SESSION_SECRET, CRON_SECRET — длинные случайные строки (openssl rand -hex 32)
#   ADMIN_PHONE — ваш номер, по нему вход в админку
#   APP_URL=http://<IP сервера>, SITE_ADDRESS=:80

# 4. Запуск (сборка ~3–5 минут)
docker compose up -d --build

# 5. Проверка
docker compose ps
curl http://localhost/api/health
```

Сайт откроется по `http://<IP>/ru`.

**Первый вход в админку.** Пока каналы отправки кода не подключены, код пишется в лог сервера:
```bash
docker compose logs app | grep otp
```
Войдите по `ADMIN_PHONE` → **Настройки → Подтверждение номера** → подключите WhatsApp / Telegram / SMS.

**Подключение домена.** A-запись домена → IP сервера. В `.env`:
```
SITE_ADDRESS=example.am, www.example.am
APP_URL=https://example.am
COOKIE_SECURE=true
```
Затем `docker compose up -d`. Caddy сам выпустит и будет продлевать SSL-сертификат.

**Обновление.** `git pull && docker compose up -d --build` (миграции применяются автоматически).

**Бэкапы.** Ежедневно в `./backups/db-YYYY-MM-DD.sql.gz`, хранятся 14 дней. Восстановление:
```bash
gunzip -c backups/db-2026-09-16.sql.gz | docker compose exec -T db psql -U app homeservices
```
Фото из админки лежат в docker-томе `uploads`. Рекомендуется копировать `backups/` и том `uploads` на внешнее хранилище.

## Подключение каналов кода

| Канал | Что нужно | Где указать |
|---|---|---|
| WhatsApp | Meta Business → WhatsApp Cloud API: Phone Number ID, постоянный Access Token, одобренный шаблон категории *Authentication* | Настройки → WhatsApp Cloud API |
| Telegram | [Telegram Gateway](https://core.telegram.org/gateway) — токен API, пополненный баланс | Настройки → Telegram Gateway |
| SMS | Аккаунт Twilio (SID, Token, номер отправителя). Местного SMS-провайдера можно добавить в `src/server/otp.ts` | Настройки → SMS |

Уведомления команде о новых заказах, отменах и отзывах: создайте бота через @BotFather, добавьте в рабочий чат, укажите токен и ID чата в **Настройки → Уведомления**.

## Структура

```
prisma/schema.prisma          модели БД
prisma/seed.ts                стартовые данные (тарифы, категории, демо-мастера)
messages/*.json               тексты интерфейса
src/lib/pricing.ts            движок цены (+ тесты)
src/lib/slots.ts              свободные слоты (+ тесты)
src/lib/recurrence.ts         даты визитов подписки (+ тесты)
src/server/services/          бизнес-логика: каталог, бронирование, промокоды, визиты
src/server/actions/           server actions: клиент, мастер, админка
src/app/[locale]/(site)/      клиентская часть
src/app/[locale]/pro/         кабинет мастера
src/app/[locale]/admin/       админка
src/app/api/cron              фоновые задачи (визиты подписок, авто-возобновление пауз, истёкшие пакеты)
docker-compose.yml, Dockerfile, deploy/Caddyfile
```
