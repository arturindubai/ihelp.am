# Сквозные проверки

`order.mjs` — главный сценарий: клиент на телефоне оформляет заказ, данные проверяются в базе и в админке, тестовые записи удаляются. Прогонять после изменений в оформлении заказа, входе, расписании и админке.

Нужны Node 20+, пакет `playwright` и браузер Chrome. Если playwright не установлен в проекте, укажите путь к нему и к браузеру:

```bash
cd /opt/ihelp.am
TOKEN=$(grep '^ADMIN_LOGIN_TOKEN=' .env | cut -d= -f2) \
PW=/root/.npm/_npx/*/node_modules/playwright/index.mjs \
CHROME=/путь/к/chrome \
node e2e/order.mjs
```

`TOKEN` включает проверку админки, `KEEP=1` оставляет созданные данные для ручного разбора, `PHONE` и `SERVICE` меняют тестовый номер и услугу.

Скрипт сам подставляет код входа (каналы доставки ещё не подключены, AUTH-1): хэш считает контейнер приложения, секрет наружу не выходит.
